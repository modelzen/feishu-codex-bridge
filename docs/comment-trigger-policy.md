# 文档评论触发策略

管理员在机器人私聊管理台 → 全局设置 → 云文档评论中选择：

- **仅管理员 @**（默认）：仅机器人 owner 或管理员可触发。
- **任何评论者 @**：带有已识别评论者身份的真实 @ 评论均可触发，包括外部协作者。

按钮立即保存，下一条新评论起生效，无需重启。设置作用于当前机器人的所有可访问文档，与群聊参与策略独立。仅管理员可修改此设置；开放评论触发不会使评论者成为桥接管理员。

配置文件对应字段：

```json
{
  "preferences": {
    "comments": {
      "triggerPolicy": "any_mention"
    }
  }
}
```

`admin_mention` 为默认值；缺失或无效值都按该默认处理。编辑已有配置时保留其他字段。手动编辑配置文件后需重新加载服务，设置卡修改则立即生效。

允许任何评论者后，他们会使用现有评论 Agent、提示词及权限，包括已有的文档修改能力。该设置不授予机器人额外文档访问权限，也不能解决飞书 @ 选择器无法选择机器人或事件未送达的问题；纯文本写出机器人名字不会绕过真实 @ 校验。没有评论者身份、未 @ 或不支持的文档类型仍被拒绝。
