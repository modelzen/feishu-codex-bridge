# Prototype — feishu-codex-bridge UI 预览

**问题**：DM 机器人菜单 + 项目群（置顶横幅 + 会话配置卡）+ 话题 thread（会话设置/流式/中止）这套交互面，放在真实飞书 UI 里感觉对不对？

**形态**：一次性高保真 HTML，单文件，浏览器打开即看。不是"3 个视觉变体"，是**一套设计 × 多屏/多状态**，底部浮条 / ←→ 方向键 / 点卡片按钮 切换。

**屏幕清单**（11 屏）：
- 私聊：首页+机器人菜单 / 新建项目 / 指定现有文件夹 / 创建成功 / 项目列表 / 删除确认 / 全局设置 / 诊断
- 项目群：@bot 会话配置卡（含置顶横幅）/ 恢复历史会话
- 话题：运行中（流式+工具+⏹中止+steer）/ 卡死中止

**运行**：`open prototype/feishu-ui-prototype.html`

**结论**：✅ 设计已对齐并落档 → `docs/design/feishu-codex-bridge-design.md`。
关键 UI 纠偏：飞书话题无"头部卡/话题级置顶"，故会话设置挂在**最新运行卡**的 `⚙️`（旧卡 patch 移除）；群/话题里**卡片底部按钮行即菜单**（机器人自定义菜单仅单聊）。
开始实现后把验证过的设计折进真实代码，删掉本原型。
